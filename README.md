# 🚀 Estudos de JavaScript

Repositório dedicado aos meus estudos práticos e evolução na linguagem JavaScript, focando em lógica de programação, manipulação de arrays e automação de tarefas cotidianas.

## 📂 Conteúdo do Repositório

* **`arrays-academia.js`**: Script focado no controle e análise de dados de rotina e treinos (lógica de arrays e loops).
* **`arrays-videosvirais.js`**: Algoritmo para filtragem de métricas e visualizações de conteúdos digitais.
